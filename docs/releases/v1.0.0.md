# TRAE SOLO CN Enhancer v1.0.0

Release date: 2026-09-14

Release type: internal / small-scale test release

Signing status: unsigned. Windows SmartScreen may show an unknown-publisher
warning.

## Highlights

- Multiple TRAE SOLO CN accounts with independent local authentication backups.
- Transactional account switching with automatic rollback.
- Seamless OAuth and traditional fake-logout login.
- Encrypted account import/export.
- Per-account phone, plan, remaining-credit, check-in, and keep-alive status.
- Daily automatic check-in with account-scoped device identifiers.
- Automatic keep-alive for inactive accounts and safe active-account
  synchronization.
- Portable executable, per-user installer, optional logon autostart, tray host,
  service supervisor, and redacted rotating logs.

## Requirements

- Windows 10 or Windows 11, x64
- TRAE SOLO CN installed
- No Node.js installation is required for the portable executable or installer

## Install

Run `TraeEnhancer-Setup-1.0.0.exe`. The installer is per user, does not require
administrator rights, and keeps the install-location page enabled.

The installer detects TRAE SOLO CN strictly. If detection is wrong or fails,
select `TRAE SOLO CN.exe` manually. The selected path is validated and saved
through `TraeEnhancer.exe configure`.

Windows SmartScreen may warn because this build is not digitally signed. Verify
the SHA-256 value before choosing to run it.

## Upgrade and reinstall

Run the newer installer over the existing installation. The installer keeps the
stable application ID, previous install directory, and previous task choices. It
stops the old service before replacing files. The `data` directory is preserved.

## Uninstall

The interactive uninstaller asks whether to keep `data`. Silent uninstall keeps
user data by default.

`data` contains account authentication snapshots, the API token, and local
configuration. Removing it is irreversible.

## Known limitations

- The executable and installer are not digitally signed.
- There is no online auto-updater. Upgrades are installed manually.
- The release supports Windows x64 only.
- Check-in and keep-alive schedules are fixed; they are not yet configurable from
  the UI.
