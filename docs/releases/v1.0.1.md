## 本次更新

- 修复 TRAE 未登录时误报“自动纳管当前账号失败”的问题，改为显示“TRAE 尚未登录”。
- 无感登录和假退出新增账号后，daemon 会立即同步该账号的签到、套餐和余额，不再停留在“额度未同步 / 套餐未知 / 待签到”。
- 新账号保存后立即显示登录信息有效期，不需要等待下一次后台维护。
- 切换账号只在登录信息临近到期时更新，避免因为切换动作本身无谓换票。
- 新增非当前账号删除功能。删除前需要输入“删除”确认，当前正在使用的账号不能删除。
- 设置页改为“签到 / 更新 / 维护”分组，降低配置页面的信息密度。
- 关于页改为面向普通用户的使用说明，包含添加账号、切换账号、换电脑和数据安全说明。
- 发布分支移除代理配置、代理 UI、代理路由、系统代理读取和代理诊断。
- 发布分支启动后台服务时会移除继承的代理环境控制，确保使用直连。
- README 已改为中文，后续提交信息和发布说明统一使用中文。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示风险。
- 当前没有在线自动更新功能，升级需要覆盖运行新版安装包。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 当前仅支持 Windows 10/11 x64 和 `TRAE SOLO CN`。
