# TRAE SOLO CN 增强助手 v1.4.0

发布日期：2026-10-02  
发布类型：正式版（功能更新）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者  
网络：更新下载复用设置页里配置的代理，默认直连。

## 本次更新

- 「立即升级」不再是跳去下载页：现在点了就在面板里直接把新版下下来并装上，全程不用离开 TRAE，也不用自己找安装包、不用去双击 exe。
- 点击后会弹出一个升级进度框，实时显示「正在下载安装包 xx%」→「正在校验安装包」，不再是一条看不到进展的提示。下载过程中这个框挡住面板，避免误触。
- 校验通过后，安装向导窗口由助手直接拉起，你只需要在向导里按提示点「下一步」。安装期间助手服务会短暂停止，向导结束后回到面板点「重载界面」即可。
- 升级在进行中就是进行中：升级开始后按钮会变成「升级中…」，重复点击只会被拒并继续显示进度，不会再误报「安装失败」，也不会真的再下一遍。
- 安装向导由后台服务拉起后，可能只出现在任务栏而没有浮到 TRAE 前面——这是 Windows 的窗口机制决定的，不是升级卡住。如果没看到向导窗口，请到任务栏点一下「TRAE SOLO CN Enhancer 安装」。如果中途把向导关掉了，面板会提示「本次升级没有完成」，按钮恢复可用。
- 下载失败时只会看到一句能照着做的话（例如「下载安装包超时：网络太慢或连接中断，请检查网络或代理设置后重试」），不再把 `UND_ERR_BODY_TIMEOUT` 这类底层错误直接甩到界面上。完整的技术原因仍然写进 `logs/daemon.log`，方便排查。
- 安装包下载的超时只有一处定义：10 分钟。此前底层 HTTP 库里那个 5 分钟的默认值会先一步掐断下载，还把人看不懂的错误报出来，现在已对齐。
- 关掉失败提示框之后，按钮仍然是「重试」，不会退回「立即升级」，也不会自己再弹出一个停在某个百分比的假进度框。
- 重试不再重新下载一遍：如果你取消过安装向导，之前已经校验通过的安装包还在临时目录里，重试会直接复用它并跳到校验那一步；只有文件不在了或校验对不上才重新下载。
- 只有你点了「立即升级」才会下载和安装。后台的自动检查永远只负责提示，不会自动下载，也不会自动安装。
- 安装包必须先自证身份才会被下载：文件名必须是 `TraeEnhancer-Setup-<版本>.exe`，必须已上传完成、带文件大小、带 sha256 校验值，并且托管在 github.com。任何一项不满足都直接拒绝并说明缺的是哪一项，绝不「先下下来再说」。
- 下载过程中边写盘边算 sha256，下载完先比大小、再比校验值。对不上就把文件删掉并报错，绝不拿一个来路不明的安装包去安装。
- 安装包下载到系统的临时目录 `%LOCALAPPDATA%\Temp\TraeEnhancer-Update\`，不写进 `data\`。失败会立刻清掉半成品；下载成功的文件要留给安装向导使用，之后在下次助手启动时再扫一遍清掉。
- 更新下载与签到、续签、切换账号、登录共用同一把互斥锁：这些操作正在进行时不会同时下载安装，反之亦然。
- 安装程序结束时由安装包自己把助手服务拉回来，不依赖你在向导最后一页勾没勾「启动」。这是升级流程必须补上的一步：安装前会先停掉旧服务，如果不主动拉起，面板就会一直不回来。
- 万一没回来，重新打开一次桌面快捷方式即可；「重载界面」按钮保留为手工兜底。
- 安装失败只显示原因和一个「重试」按钮，不出现任何外链。
- 移除了旧版「立即升级」跳转下载页所用的接口。
- 账号卡新增「积分构成」：点卡片上的饼图图标就地展开该账号的积分明细，上方是「即将到期」（按到期时间排序，并写明还剩几天），下方是「全部构成」（每笔积分的来源、剩余数量与到期日）。
- 有积分即将到期时，饼图图标右上角会出现一个小红点，不翻开明细也知道要留意。
- 设置页「签到」卡新增「积分到期提醒」，可以选多少天算「即将到期」（1 / 3 / 7 / 14 / 30 天，默认 7 天）。保存即生效，不用重启助手。
- 回到桌面后双击快捷方式重新打开 TRAE 时，窗口会被带到最前面：最小化了就先恢复，已在后台就先激活。只有确实拿不到窗口才会提示，不再出现「TRAE 明明已经显示出来，却提示没能调到最前面」的误报。
- 修复积分明细弹层内容较多时右侧滚动条拖不动、鼠标一靠近弹层就消失的问题。
- 检查更新失败时，面板只显示一句「网络连接失败」，不再把接口地址、超时毫秒数这类内部信息显示在界面上；完整原因仍然写进 `logs/daemon.log`，方便排查。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示未知发布者。安装包是助手自己写盘的，不带浏览器下载特有的「来自网络」标记，因此未必弹出提示；这里不做保证，请以实际提示为准。
- 检查更新需要能访问 GitHub。网络受限时请在设置页「网络」里配置代理，更新下载会走同一个代理。
- 「下载 + 校验」这两步已用真实发布资产实测通过（大小与 sha256 均与发布信息一致）；「安装向导 + 服务自动回来」这条链路只能在下一个版本发布后，由这一次真实升级来走通。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 手动续签会让同一账号在其他设备上的登录信息失效，仅在有意为之的场合使用。
- 代理认证只支持用户名 + 密码，暂不支持企业代理常用的 NTLM / Kerberos 认证。
- 代理账号密码在本机是明文存放（按需求如此），请不要把 `data/config.json` 外发。
- 当前仅支持 Windows 10/11 x64 和 `TRAE SOLO CN`。
