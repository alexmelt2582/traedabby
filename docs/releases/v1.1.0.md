# TRAE SOLO CN 增强助手 v1.1.0

发布日期：2026-09-21  
发布类型：正式版  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者  
代理功能：不包含；完整代理实现保留在 `feature/proxy-support` 分支，本发布包只使用直连网络。

## 本次更新

- 新增账号级设备身份：每个账号持有一套独立的设备号、机器号、硬指纹与 EC 密钥对，被该账号的登录与刷新固定复用，规避官方"单设备可绑定账号数"触顶。
- 采纳 TRAE 现有账号时，复用其原本绑定的设备身份与签名密钥，避免 deviceId 与密钥错配导致凭据刷新校验失败。
- 安装器检测到已安装版本时，提示重新安装或取消，避免在覆盖安装时静默中断。
- 提交信息与发布说明统一使用中文。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示风险。
- 当前没有在线自动更新功能，升级需要覆盖运行新版安装包。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 当前仅支持 Windows 10/11 x64 和 `TRAE SOLO CN`。
