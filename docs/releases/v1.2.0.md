# TRAE SOLO CN 增强助手 v1.2.0

发布日期：2026-09-25  
发布类型：正式版（功能更新）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者  
网络：不含代理配置，全部直连。

## 本次更新

- 新增助手更新检查：发现新版本时「关于」页会亮起小红点，可查看更新内容并直接打开下载页。
- 设置页新增「更新」分组：可以开关后台自动检查，也可以点「立即检查」手动查一次。只读取公开的发布信息，不涉及账号数据。
- 新增账号手动续签：非活跃账号可一键把登录信息有效期推后。同一账号在其他设备上的副本会因此失效，点击前会明确提示。
- 删除账号不再要求手动输入「删除」，点击确定即可完成。
- 重做注入面板的「设置」与「关于」页：设置页按签到 / 更新 / 维护分组，控件改为「左名称 + 右控件」的行；关于页改为版本号、更新内容与三步上手；面板宽度由 460px 提到 540px。
- 修复 TRAE 装在非默认盘（例如 D 盘）时首次安装检测不到主程序的问题：注册表检测改为按卸载项里的主程序名定位，不再依赖默认安装目录。
- 修复设置页标题显示为「账号 0」、关于页版本号重复出现、签到卡重复说明三处界面缺陷。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示风险。
- 更新检查只负责提示，不会自动下载或安装；升级仍需运行新版安装包。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 手动续签会让同一账号在其他设备上的登录信息失效，仅在有意为之的场合使用。
- 当前仅支持 Windows 10/11 x64 和 `TRAE SOLO CN`。
