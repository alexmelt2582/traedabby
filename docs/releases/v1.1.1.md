# TRAE SOLO CN 增强助手 v1.1.1

发布日期：2026-09-25  
发布类型：正式版（维护版本）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者  
代理功能：不包含；完整代理实现保留在 `feature/proxy-support` 分支，本发布包只使用直连网络。

## 本次更新

- 发布方式改为本地打包：验收通过后在本地构建并发布，不再依赖 GitHub Actions，构建环境与验收环境一致。
- 新增本地发布命令 `npm run release:pack`（构建并汇总发布产物）与 `npm run release:publish`（校验后创建 Release 并上传产物）。
- 发布前会校验发布说明、产物、标签与代码状态，任一不通过即中止，不会产生半成品发布。
- 便携版压缩包按显式清单打包并在打包后校验内容，本地运行产生的数据目录不会进入发布包。
- 功能代码与 v1.1.0 相同，本次只调整发布流程与文档。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示风险。
- 当前没有在线自动更新功能，升级需要覆盖运行新版安装包。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 当前仅支持 Windows 10/11 x64 和 `TRAE SOLO CN`。
